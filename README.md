# 🎯 Interview Preparation Coach

Simulate job interviews for graduating students.

**Author:** Pranay M

## Features
| Module | Description |
|--------|-------------|
| Question Generator | Generate interview questions |
| Answer Evaluator | Evaluate responses |
| Mock Interviewer | Conduct mock interviews |
| Feedback Provider | Provide feedback |
| Industry Researcher | Research industries |
| Company Analyzer | Analyze companies |
| Behavioral Coach | Coach behavioral questions |
| Technical Assessor | Assess technical skills |
| Confidence Builder | Build confidence |
| Progress Tracker | Track progress |
